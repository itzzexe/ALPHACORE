## The API

The whole surface is described by a generated OpenAPI document, so it cannot
drift from the code: [`app/public/openapi.json`](../app/public/openapi.json),
served live at `/api/openapi.json` and regenerated by `npm run openapi`. Each
path carries the permission it actually demands, because the generator runs the
real resolver rather than reimplementing it.

---

**A note on precedence.** The blueprint was written first and the platform was
built from it, so the two disagree in places. Where they do, the platform is
what is true: its counts are measured by `npm run readme:check` on every build,
and the blueprint is a record of what was intended.
