# The blueprint

Eleven documents written before the platform existed, arguing for a company run
by an AI workforce with humans holding every gate. [AlphaCore](../../README.md)
is what was built from them.

They are kept because the reasoning is the useful part — the decisions, the
trade-offs, and the objections raised against them. Where a document and the
running platform disagree, **the platform is what is true**: its numbers are
measured from the code on every build, and these are a record of what was
intended.
